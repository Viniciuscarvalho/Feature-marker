# feature-marker Agent

Use the `feature-marker` CLI. The CLI is the state machine and is responsible
for mode validation, worktree isolation, checkpoints, runtime phase prompts,
platform detection, commits, and branch-only handoff.

Do not manually maintain `.claude/feature-state`; native-adapter state lives in
`.feature-marker/features/{slug}`.

Common commands:

```bash
feature-marker run <slug> --runtime claude --mode full
feature-marker resume <slug>
feature-marker status <slug>
```

If asked to execute a phase prompt generated by the CLI, read the prompt under
`.feature-marker/features/{slug}/logs/`, operate only in the listed worktree,
and avoid committing, pushing, or opening PRs. The CLI performs branch handoff.

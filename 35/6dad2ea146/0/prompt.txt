# Plan: MCP Awareness + Skill as Dispatcher

## Context

Feature-marker already has stack detection (`lib/stack-detector.sh`), context gathering, and prompt enrichment — but it has **zero MCP awareness** beyond a single boolean `xcodebuildmcp_available` in the iOS detector. The ios-workflow skill hardcodes XcodeBuildMCP usage but doesn't generalize to other MCPs.

This plan adds two interconnected features:

1. **MCP Awareness** — detect configured MCP servers across all agent config files, generate `environment_manifest.json`
2. **Skill as Dispatcher** — new directory structure (`scripts/`, `references/mcp-adapters/`, `references/stack-patterns/`, `templates/`) so SKILL.md can load the right references based on detected environment

## environment_manifest.json Format

```json
{
  "version": "1.0",
  "detected_at": "ISO timestamp",
  "stack": {
    /* ...full platform-context.json content... */
  },
  "mcps": [
    {
      "name": "XcodeBuildMCP",
      "server_key": "xcodebuildmcp",
      "category": "build",
      "source": ".claude/settings.json",
      "adapter": "references/mcp-adapters/xcodebuild.md",
      "tools_hint": ["discover_projs", "session_set_defaults", "build_run_sim"]
    }
  ],
  "clis": [
    { "name": "swiftlint", "available": true },
    { "name": "docker", "available": true }
  ],
  "ci": {
    "detected": true,
    "type": "github-actions",
    "config_path": ".github/workflows/"
  }
}
```

## Design Decisions

1. **`environment_manifest.json` is a superset** — embeds full `platform-context.json` + MCP + CLI + CI data. `platform-context.json` still written separately for backward compat.
2. **Config-based detection, not runtime** — we scan config files, never call MCP servers during discovery.
3. **Adapters loaded lazily** — SKILL.md only reads adapter files for detected MCPs. Keeps context window small.
4. **MCP failures are always non-blocking** — CLI fallback is always the primary path; MCPs enhance, never gate.
5. **Case-insensitive matching with aliases** — handles "xcodebuildmcp", "XcodeBuildMCP", "xcode-build-mcp".
